Find a layer on ArcGIS Online

Search results appear here. Only public Feature and Map layers are shown — private or Esri-only layers won’t work with this tool.

How to use

  1. Paste the layer address (it ends in /FeatureServer/0 or /MapServer/3) and press Add to map. A service address without a number adds all of its layers. Don't have an address? Press Find layer… next to the bar to search ArcGIS Online by place or topic (e.g. “parcels Nodaway County”) and add a result with one click — only public Feature/Map layers are shown, since that's the only kind this tool can read.
  2. Use Go to place on the ribbon to jump the map to any address, city, state, or country — or paste raw coordinates like 41.85, -87.65 (lat, lon) to jump straight there. Powered by OpenStreetMap's free search, so results are place names and addresses, not parcel data.
  3. Big layers such as county parcels only draw once you zoom in (the minimum zoom is shown on the layer card). Zoom in, then click any shape to see its attributes.
  4. Use Definition query on the layer card to filter, for example municipality = 'OAK PARK'. The Attribute table lists what is loaded in the current view.
  5. Press Shapefile, KML, KMZ or GeoJSON. Choose the map view, a box you drew, or the entire layer, then press Download. Tick “Download every matching feature” to remove the size limit entirely and fetch everything that matches, however many features that is — for a county-wide parcel layer this can be a large file and take a while, since ArcGIS servers only return a few thousand features per request.
  6. Shapefiles come as a .zip. Unzip it before opening in ArcGIS or QGIS. Shapefile field names are cut to 10 characters, so a _field_names.txt file lists the original names.
  7. Some servers (for example gis.cookcountyil.gov/traditional/…) refuse browser requests because they send no CORS header, even though the address opens fine in a tab. Leave Connection on Auto and the layer is retried through a public proxy; a notice appears when that happens. Public proxies are rate limited, so for a big download use your own proxy address in the box next to it, with {url} where the target address goes.

Everything runs in your browser. Nothing is uploaded anywhere except the requests sent to the ArcGIS server you entered.
